# Oversight Sentinel: Ethical Agent for Zero-Fee Recruitment

Oversight Sentinel is an autonomous auditing agent built for the **Google Cloud Rapid Agent Hackathon (2026)**. It is designed to detect and block exploitative recruitment fees in global labor corridors.

## 🚀 Mission
To move beyond simple chatbots and create a reasoning agent that proactively protects vulnerable workers by enforcing a **Zero-Fee Guarantee** across the Uganda–Canada–UAE–EU corridors.

## 🧠 Tech Stack
- **Reasoning Engine:** Gemini 3 Flash (Google Cloud Vertex AI)
- **Orchestration:** Google Cloud Agent Builder
- **Memory/Superpower:** MongoDB Atlas via **Model Context Protocol (MCP)**
- **Infrastructure:** Google Cloud Run (Stateful Logic Hosting)

## 🛠️ Key Features
- **Automated Ethical Audits:** Analyzes job descriptions for "pay-to-play" language.
- **MCP Database Integration:** Real-time cross-referencing with a historical "Bad Actor" database.
- **Multi-Step Reasoning:** Plans and executes company verification missions autonomously.
